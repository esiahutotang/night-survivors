# New skin artwork

Generated with the built-in ImageGen tool. The original `assets/hero.png` was
provided as a style reference; original art was not edited. Both outputs use a
transparent background. The game scales them with nearest-neighbour sampling
to the original hero sprite size, and uses larger previews on the title screen.

## Scarlet mage

Output: `assets/hero_mage.png`

Prompt: Create ONE new playable character sprite for a tiny top-down survival
game, using the attached 48x48 knight as a STYLE REFERENCE only. Original
character: a cute scarlet fire mage, huge red pointed wizard hat, orange-gold
trim and little face hidden under hat, compact red robe, two stubby boots.
Match the reference's extremely simple chunky retro 16x16-pixel game sprite
aesthetic: dark plum outline, tiny fixed palette, flat pixel clusters, no smooth
gradients or 3D, front-facing full body. Square composition, character centered
and filling 85 percent of both dimensions, generous transparent edge of about
one pixel at logical 16px resolution. No text, no shadow, no backdrop, no ground,
no weapon projectile, ONE isolated character only. Actual transparent background.
Render as sharply scaled pixel art intended for a 48x48 game sprite.

## Emerald ranger

Output: `assets/hero_ranger.png`

Prompt: Use case: stylized-concept. Create ONE transparent playable character
sprite for a top-down tiny survivors game. Reference image is the existing
knight sprite and shows the intended very simple chunky pixel style. New
character: emerald forest ranger, a deep green pointed hood framing a tiny pale
face, bright mint shoulder trim, short green cape, brown diagonal leather strap
and belt, stubby brown boots. Front-facing full body, squat chibi proportions,
two small dark eyes. Draw as extremely low-resolution pixel art with a logical
24x24 grid, sharply enlarged, dark plum pixel outline, flat limited palette, no
gradients, no painting, no realistic textures. Single sprite centered filling
85% of the square canvas. Actual transparent background. No text, no scenery,
no floor, no shadows, no duplicate figures, no projectiles. Intended to be
displayed at only 48x48 pixels in-game, so keep details very simple and readable.
